# Linux Process Lab

Small experiments that connect Linux processes and threads to Java backend
applications.

## Labs

- `01-fork`: process creation with `fork(2)`
- `02-exec`: program replacement and process memory
- `03-thread`: native threads
- `04-java-thread`: JVM threads
- `05-spring-tomcat`: Spring Boot, embedded Tomcat workers, and CPU scheduling

Build artifacts are ignored. Commit source files and lab notes only.
